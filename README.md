# Зоопарк ИИ — моделирование энергии адсорбции

Учебный проект УрФУ (ИРИТ-РТФ) для заказчика **ООО «ЦИФРОВЫЕ РЕШЕНИЯ»**.

Веб-приложение в режиме «одного окна» на базе **Python + Streamlit + SQLite**, которое позволяет подобрать подходящую ML/AI-модель под задачу предсказания энергии адсорбции ($E_{\text{ads}}$), получить рекомендации по применению и ограничениям, а также выполнить расчет полностью локально на CPU.

> **Примечание по этапам:** на текущем этапе (Демо 2) фокус смещен на модели предсказания энергии адсорбции веществ. Наработки Демо 1 по экстракционным каскадам сохранены в `models/legacy_extraction/`.

## Модели в «зоопарке»

| Модель | Тип | Режим в приложении | Требования |
| :--- | :--- | :--- | :--- |
| **MXene Gas Sensor (Zenodo)** | Табличный ML (`scikit-learn`) | Локальный расчет | CPU |
| **MACE-MP-0 (small)** | Межатомный потенциал (MLIP) | Локальный расчет | CPU |
| **AdsMT** | Мультимодальный трансформер | Каталог-советчик | Linux + NVIDIA GPU |
| **LEI-framework** | Графовая нейросеть (GNN) | Каталог-советчик | GPU / PyG |
| **OC20 / FAIRChem** | Предобученные GNN для катализа | Каталог-советчик | Серверный GPU |
