# Зоопарк ИИ-моделей для гидрометаллургии

## О проекте

Проект представляет собой прототип программного комплекса для моделирования и сравнения различных подходов к расчёту экстракционных каскадов в гидрометаллургии.

Приложение позволяет задавать технологические параметры, запускать моделирование и сравнивать результаты работы нескольких моделей.

**Заказчик:** ООО «ЦИФРОВЫЕ РЕШЕНИЯ».

## Возможности приложения

- Выбор одной или нескольких моделей для сравнения.
- Настройка количества ступеней экстракционного каскада.
- Задание начальной концентрации.
- Настройка соотношения потоков.
- Построение графика изменения концентрации по ступеням.
- Отображение итоговых показателей моделирования.

## Используемые технологии

- **Python** — основной язык программирования.
- **Streamlit** — создание пользовательского интерфейса.
- **NumPy** — математические вычисления.
- **Matplotlib** — построение графиков.
- **Git и GitHub** — контроль версий и совместная разработка.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/azatyz/Zoo_AI.git
```

### 2. Переход в папку проекта

```bash
cd Zoo_AI
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
streamlit run app.py
```

После запуска приложение откроется в браузере.

## Описание моделей

В проекте предусмотрено три подхода к моделированию:

- **Классическая модель** — использует упрощённую математическую зависимость для демонстрации изменения концентрации.
- **ML-модель** — демонстрационная реализация подхода машинного обучения.
- **Гибридная модель** — демонстрирует объединение результатов классического и ML-подхода.

> Важно: текущая версия является демонстрационным прототипом. Используемые расчётные зависимости и результаты пока не прошли проверку на реальных экспериментальных данных. Полученные значения не следует рассматривать как подтверждённые технологические прогнозы.

## Текущий статус

Реализован MVP с пользовательским интерфейсом, настройкой параметров моделирования, выбором моделей, построением графиков и сравнением результатов.

Дальнейшее развитие предполагает совершенствование моделей, использование экспериментальных данных и проверку качества расчётов.
