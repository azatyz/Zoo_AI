# Гид по моделям «Зоопарка ИИ»

Все модели предсказывают энергию адсорбции **E_ads (эВ)**: E_ads = E(поверхность + молекула) − E(поверхность) − E(молекула). Чем она отрицательнее, тем выгоднее (прочнее) адсорбция; значения около нуля или положительные означают слабое или невыгодное связывание.

Две модели считаются локально на CPU, три работают в режиме каталога-советчика: они показывают ограничения и рекомендации, но расчёт не запускают (нужен GPU).

---

## 1. MXene Gas Sensor ML (XGBoost) — локальный расчёт, CPU

- **Подходит для:** быстрой оценки E_ads газа на MXene при выборе материала для газового сенсора; сравнения нескольких MXene или газов между собой.
- **Что подаётся на вход:** формула MXene из датасета (например, `Ti2CO2`) и газ из набора CH4, CO, H2S, HCHO, NH3, NO, NO2, SO2. Признаки (17 дескрипторов) модель берёт из готовой таблицы образцов.
- **Что выдаёт:** E_ads в эВ для сайта адсорбции top_M, а также эталонное значение из датасета и абсолютную ошибку относительно него; показывает метрики модели на тесте.
- **Ограничения и когда не применять:** работает только на готовых образцах (240 MXene × 8 газов), произвольную формулу или новый газ ввести нельзя. Для образцов из обучающей выборки ошибка занижена, ориентируйтесь на пометку train/test. Не подходит для других материалов и сайтов адсорбции.

## 2. MACE-MP-0 (small) — локальный расчёт, CPU

- **Подходит для:** оценки E_ads молекулы на поверхности для разных материалов и молекул, когда нужен физический расчёт, а не табличная модель; быстрой проверки готовых структур.
- **Что подаётся на вход:** либо имя готового пресета (например, `Cu111_CO`), либо три файла `.xyz` / `.cif`: система (поверхность + молекула), чистая поверхность и молекула отдельно. Состав системы должен совпадать с суммой поверхности и молекулы.
- **Что выдаёт:** E_ads в эВ, а также энергии трёх структур, число атомов и предупреждения (например, о нереалистичном значении).
- **Ограничения и когда не применять:** это одиночный расчёт энергии (single-point) без релаксации геометрии, поэтому значение ориентировочное. Система не больше 300 атомов, атомы не ближе 0,6 Å. Для точных количественных выводов нужен расчёт методом DFT.

## 3. AdsMT — каталог-советчик, нужен GPU

- **Подходит для:** задач каталитической адсорбции, когда известна структура поверхности и адсорбата, а положение адсорбата (сайт) заранее не задано.
- **Что подаётся на вход:** структура поверхности и адсорбата в виде атомной структуры.
- **Что выдаёт:** оценку энергии адсорбции E_ads в эВ.
- **Ограничения и когда не применять:** мультимодальный трансформер, которому нужны Linux и видеокарта NVIDIA, поэтому в приложении локально не запускается. Подходит для тех систем, на которых он обучен; для других материалов точность не гарантирована.

## 4. LEI-framework — каталог-советчик, нужен GPU

- **Подходит для:** предсказания E_ads по локальному окружению места адсорбции: каталитические поверхности, газовые сенсоры, захват углерода, хранение энергии.
- **Что подаётся на вход:** кристаллическая структура поверхности с адсорбатом, из которой строится описание ближайшего окружения атома адсорбции (графы Вороного и «отпечатки» признаков).
- **Что выдаёт:** оценку E_ads в эВ.
- **Ограничения и когда не применять:** в приложении расчёт недоступен, так как нужны GPU и библиотека PyG. Модель опирается на локальное окружение, поэтому нужно знать, где адсорбируется молекула; точность зависит от данных, на которых её обучали.

## 5. OC20 / FAIRChem — каталог-советчик, серверный GPU

- **Подходит для:** катализа: оценка энергий и сил для систем «поверхность + адсорбат» на предобученных графовых нейросетях проекта Open Catalyst.
- **Что подаётся на вход:** атомная структура поверхности с адсорбатом (адсорбционная конфигурация).
- **Что выдаёт:** энергию системы и силы на атомах, из которых получают E_ads в эВ.
- **Ограничения и когда не применять:** тяжёлые модели, рассчитанные на серверный GPU, на обычном ноутбуке не запускаются. Лучше работают на типах систем, близких к обучающему набору OC20; для других материалов и молекул проверяйте результат.

---

*Все значения E_ads предварительные. Для публикации и точных выводов их нужно подтверждать расчётом методом DFT или экспериментом.*
